# Каталог відео

Статичний клієнтський каталог для впорядкування YouTube-відео за альбомами,
розділами та підрозділами. Дані зберігаються у JSON-файлах у `data/`;
браузер завантажує та редагує їх без серверної частини.

Інструкції з локальної розробки та архітектури дивіться у
[посібнику розробника](docs/DEVELOPMENT.md). Інструкції для користувачів —
в [україномовному посібнику](manual.html).
