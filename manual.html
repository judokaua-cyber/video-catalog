🔧 Developer Notes

Передмова

Це каталог YouTube-відео — сайт, який збирає посилання на відео в тематичні альбоми. Відео зберігаються не на сайті, а на YouTube; тут лише зручний покажчик: обкладинки, назви, розділи, пошук.

Каталог працює у браузері. Окремої програми встановлювати не треба. Відкрити можна з будь-якого пристрою:

  • На телефоні — встановіть каталог як додаток на головний екран (див. нижче).
  • На ПК — просто відкрийте https://judokaua-cyber.github.io/video-catalog/ у браузері.
Як встановити на телефоні Відкрийте сайт у Chrome (Android) або Safari (iPhone) → меню браузера → «Додати на головний екран». Після цього з'явиться іконка, як у звичайної програми.

Нижче — усе, що потрібно, щоб користуватися каталогом. Якщо ви адміністратор і хочете оновлювати каталог через PyCharm або GitHub — дивіться розділ «Для адміністратора» ближче до кінця.

Навігація

Каталог має три рівні. Перехід між ними — зліва направо, кліком лівою кнопкою миші.

┌─────────────────────────────────────┐ │ Головна — список альбомів │ │ Картки: Дзюдо · Майстерня · Побут │ └──────────────┬──────────────────────┘ │ ЛКМ на картці ▼ ┌─────────────────────────────────────┐ │ Альбом — список розділів │ │ Наприклад: JUDO · Kuzushi · … │ └──────────────┬──────────────────────┘ │ ЛКМ на картці ▼ ┌─────────────────────────────────────┐ │ Розділ — картки відео │ │ Кожна з прев'ю та назвою │ └──────────────┬──────────────────────┘ │ ЛКМ на ▶ ▼ Відео відтворюється у картці

Кожна сторінка має хлібні крихти вгорі — щоб повернутися на рівень вище одним кліком.

Пошук

На сторінці розділу є поле пошуку (🔎). Введіть будь-яку частину назви відео — список фільтрується одразу.

Вигляд: сітка або список

Кнопки «▦ Сітка» та «☰ Список» змінюють вигляд карток. Сітка зручніша для перегляду прев'ю, список — для читання довгих назв.

Додати відео із закладкою

Найшвидший спосіб додати нове відео в каталог — закладка в браузері. Ви дивитесь відео на YouTube, натискаєте закладку — і відео автоматично з'являється у каталозі.

Як створити закладку

  1. Відкрийте закладки браузера (Ctrl+Shift+O у Chrome).
  2. Створіть нову закладку (правий клік → «Додати закладку»).
  3. Назву введіть будь-яку — наприклад, «📥 До каталогу».
  4. У полі URL вставте наступний код:
javascript:(function(){var u=location.href;var t=document.title.replace(/\s*-\s*YouTube\s*$/,'');var base='https://judokaua-cyber.github.io/video-catalog/add.html';window.open(base+'?url='+encodeURIComponent(u)+'&title='+encodeURIComponent(t),'_blank');})();
Копіюйте уважно Це весь код, включно з початковим javascript:. Якщо хоч один символ загубиться — закладка не працюватиме. Найкраще — виділити весь рядок, скопіювати й вставити як є, без правок.

Як користуватися

  1. Відкрийте потрібне відео на YouTube.
  2. Натисніть закладку «📥 До каталогу».
  3. Відкриється сторінка додавання — вона покаже назву відео.
  4. Виберіть альбом.
  5. Виберіть розділ (можна створити новий).
  6. Натисніть Зберегти.
Готово Через ~30 секунд відео з'явиться у каталозі. Це найшвидший спосіб — він працює і на телефоні, і на ПК.
Перший раз Якщо браузер запитає токен — вставте його один раз, і більше не питатиме. Токен зберігається тільки на вашому пристрої.

Редагування відео

На сторінці розділу кожне відео — окрема картка. З карткою можна робити кілька речей через контекстне меню (права кнопка миші) або через кнопку ⋮ на картці.

✏️ Редагувати
🔀 Переміщення / Дублювання в альбомі
📁 Перемістити в підгрупу
🗑️ Видалити відео
Чому кнопка ⋮ Коли відео відтворюється — у картці з'являється плеєр YouTube. Права кнопка миші на ньому відкриває меню плеєра, а не каталогу. Тому на кожній картці є окрема кнопка ⋮ — вона завжди відкриває наше меню, незалежно від того, чи запущене відео.

Редагувати

Відкриває форму з трьома полями:

  • Назва — те, що видно під прев'ю.
  • URL — посилання на YouTube у будь-якому форматі.
  • Розділ — випадаючий список. Зміна перемістить відео в інший розділ.
  • Підрозділ — необов'язкове поле (див. розділ «Підрозділи»).

Переміщення / Дублювання в альбомі

Дозволяє перемістити відео в інший розділ того самого альбому або створити його копію.

  • 🔀 Перемістити — відео зникає з поточного розділу й з'являється в цільовому.
  • 📋 Дублювати — створюється копія з назвою «Назва (копія)». Оригінал залишається на місці.

Видалити відео

Запитує підтвердження і видаляє відео з каталогу. Саме відео на YouTube не чіпається — воно залишається там.

Групове переміщення

Можна вибрати кілька карток і перемістити їх усі одразу.

  1. Натисніть Ctrl і клікніть на картку — вона підсвітиться.
  2. Повторіть для інших карток.
  3. Права кнопка на одній із виділених → 📁 Перемістити вибране.
  4. Виберіть підрозділ або створіть новий.
Якщо у картці запущене відео Ctrl+клік по плеєру не спрацює — плеєр перехоплює клік. Використовуйте кнопку □ на картці для виділення.

Розділи

Розділ — це група відео всередині альбому. Наприклад, в альбомі «Дзюдо» можуть бути розділи JUDO, Kuzushi, УДУШЕННЯ.

Створити новий розділ

  1. На сторінці альбому натисніть «＋ Новий розділ».
  2. Введіть назву й опис (опис — необов'язковий).
  3. Натисніть Створити.
  4. Сайт запитає: «Додати відео зараз?». Погодьтеся або відмовтеся.
Порожній розділ невидимий Розділ з'являється у списку лише після того, як у нього додано хоч одне відео. Якщо ви створили розділ, але не додали відео — він не показуватиметься.

Редагувати розділ

Права кнопка на картці розділу → Редагувати розділ. Можна змінити назву, опис або обкладинку.

Видалити розділ

Права кнопка → Видалити розділ. Усі відео цього розділу також буде видалено з каталогу (на YouTube вони залишаться).

Підрозділи

Підрозділ — це вкладений рівень всередині розділу. Наприклад, у розділі «Зачеп» можуть бути підрозділи «Зачеп ззовні» та «Зачеп зсередини».

На сторінці розділу підрозділи видно як папки:

┌─ Зачеп ─────────────────────────────┐ │ 📁 Зачеп ззовні 12 відео │ │ 📁 Зачеп зсередини 8 відео │ │ ▶ Basic Ouchi gari │ │ ▶ RUNNING STEP OUCHI GARI │ └──────────────────────────────────────┘

Усі відео розділу, які не переміщені в підрозділ, показуються знизу як звичайні картки. Клік на папку — перехід всередину підрозділу.

Як створити підрозділ

Підрозділ створюється автоматично, щойно в нього потрапляє хоч одне відео. Окремої кнопки «Створити підрозділ» немає.

  1. Права кнопка на картці відео → 📁 Перемістити в підгрупу.
  2. У вікні натисніть «＋ Новий підрозділ…».
  3. Введіть назву (наприклад, «Зачеп ззовні»).
  4. Підтвердьте переміщення.

Після цього у розділі з'явиться папка з цією назвою, а картка відео — усередині неї.

Перемістити відео в підрозділ

Права кнопка на картці → 📁 Перемістити в підгрупу → виберіть наявний підрозділ або створіть новий.

Щоб прибрати підрозділ (повернути відео в основний список), у тому ж вікні виберіть картку «(без підрозділу)».

Порожній підрозділ зникає Якщо з підрозділу прибрати всі відео — папка зникає. Це та сама логіка, що й у розділів: вони обчислюються з наявних відео, а не зберігаються окремо.

Контекстне меню (ПКМ)

Права кнопка миші на будь-якій картці відкриває контекстне меню. Це основний спосіб редагування.

Де Дії в меню
Картка альбому 📂 Відкрити · ✏️ Редагувати альбом · 📥 Завантажити JSON · 🔗 Додати посилання · 🗑️ Видалити альбом
Картка розділу 📂 Відкрити · ✏️ Редагувати розділ · 🔗 Додати відео · 🗑️ Видалити розділ
Картка відео ✏️ Редагувати · 🔀 Переміщення / Дублювання · 📁 Перемістити в підгрупу · 🗑️ Видалити відео

Меню закривається:

  • Кліком на будь-який пункт.
  • Кліком деінде на сторінці.
  • Клавішею Esc.

Типові питання

Відео не запускається

Перевірте, чи є посилання коректним. Натисніть правою кнопкою → Редагувати — подивіться, чи URL правильний.

Не можу додати відео — просить токен

Це перший раз. Вставте токен, який вам дав адміністратор. Він збережеться у браузері, і більше не питатиме.

Права кнопка не відкриває меню

Якщо у картці запущене відео — права кнопка всередині плеєра відкриває меню YouTube. Використовуйте кнопку ⋮ на картці.

Не бачу нових відео

Оновіть сторінку з очищенням кешу: Ctrl+Shift+R. Зміни на GitHub Pages з'являються за 30–60 секунд після публікації.

Для адміністратора

Ця частина — для того, хто оновлює каталог: редагує JSON, запускає Telegram-скрипт, пушить зміни на GitHub. Звичайному користувачеві вона не потрібна.

PyCharm і GitHub

Робота з каталогом ведеться через PyCharm і репозиторій на GitHub. Це дозволяє бачити історію змін, відкочувати помилки та публікувати сайт.

Репозиторій на ПК

C:\Users\Kodak\PycharmProjects\video-catalog\ ├── data\ ← файли з відео ├── js\ ← модулі JavaScript ├── section\ ← сторінка розділу ├── album\ ← сторінка альбому ├── index.html ├── manual.html ← цей посібник └── ...

Правильний цикл роботи

  1. Стягнути свіже з GitHub:
    git pull
    Робіть це перед кожним редагуванням.
  2. Внести зміни у файли (через PyCharm або через Telegram-скрипт).
  3. Закомітити ті файли, які ви змінили.
  4. Запушити:
    git push
  5. Через 30 секунд оновити сайт і перевірити з Ctrl+Shift+R.

Що саме писати в git add

Команда git add вказує, які файли будуть включені в наступний коміт. Є три типові варіанти:

Команда Що робить Коли використовувати
git add <файл> Додає один конкретний файл. Коли змінили щось одне й хочете закомітити саме його.
git add . Додає усі змінені й нові файли в поточній теці. Коли ви впевнені, що всі зміни — потрібні.
git add data/ Додає усі змінені файли в теці data/. Коли змінили кілька JSON-файлів.
Обережно з git add . Ця команда додає усі змінені файли — включно з тими, які ви, можливо, не хотіли комітити (наприклад, тимчасові тестові файли, конфіги PyCharm тощо). Якщо сумніваєтесь — спочатку виконайте git status, подивіться список, і додавайте файли по одному.

Приклад 1. Додали новий файл

Ви створили новий файл developer_notes.html у корені робочої теки C:\Users\Kodak\PycharmProjects\video-catalog\.

У PyCharm Terminal виконайте по черзі:

git pull git add developer_notes.html git commit -m "Add developer notes" git push

Приклад 2. Оновили дані альбому

Ви додали кілька відео вручну в data/judo.json і data/master.json.

git pull git add data/judo.json data/master.json git commit -m "Update judo and master videos" git push

Приклад 3. Змінили кілька файлів коду

Ви поправили section/section.js, section/section.css і додали новий js/modal-subsection-picker.js.

git pull git add section/section.js git add section/section.css git add js/modal-subsection-picker.js git commit -m "Add subsection picker" git push

Або, якщо ви впевнені, що всі зміни — потрібні, одним рядком:

git pull git add . git commit -m "Add subsection picker" git push

Як перевірити, що саме буде закомічено

Перед git add виконайте:

git status

Побачите приблизно таке:

On branch main Changes not staged for commit: modified: data/judo.json modified: section/section.js Untracked files: developer_notes.html

modified — файли, які вже є в git, але ви їх змінили. Untracked — нові файли, яких git ще не знає. Обидві категорії можна додавати через git add.

Повідомлення коміту

У -m "..." пишіть коротко, що саме змінилось. Гарні приклади:

  • "Add developer notes"
  • "Fix album counters cache"
  • "Update judo: 43 new videos"
  • "Rewrite manual: split user/admin"

Погані приклади — "fix", "update", "1". Через місяць ви не згадаєте, що це було.

Через GUI PyCharm

Замість команд у терміналі можна користуватися кнопками:

  • Ctrl+T — Pull (стягнути з GitHub).
  • Ctrl+K — Commit (закомітити зміни).
  • Ctrl+Shift+K — Push (відправити на GitHub).
Конфлікти при push Якщо push відхилено — це означає, що на GitHub є коміти, яких немає у вас. Зробіть git pull, вирішіть конфлікт (якщо є), потім знову git push. Детально — у «Ручне редагування JSON».

Імпорт із Telegram

Якщо у вас накопичились YouTube-посилання в групах Telegram — їх можна перенести в каталог масово. Для цього є окремий Python-скрипт.

Як це працює

  1. У Telegram Desktop: права кнопка на групі → Експортувати історію чату.
  2. Формат — JSON. Зніміть галочки з усіх типів вмісту, залиште тільки Текст.
  3. Скрипт telegram_to_json.py знаходить найновішу підтеку ChatExport_* і читає звідти result.json.
  4. Витягує всі YouTube-посилання, дедуплікує, тягне назви через noembed.com.
  5. Питає у вас альбом, розділ і підрозділ.
  6. Дописує нові відео у відповідний файл data/<album>.json.
  7. Пропонує запушити на GitHub.

Запуск

Подвійний клік на import_telegram.bat у теці C:\Users\Kodak\PycharmProjects\video-catalog\.

Детальна інструкція — у файлі README.txt, який лежить поряд зі скриптом.

Коли не потрібен Якщо ви додаєте відео по одному через закладку — цей скрипт не потрібен. Він для одноразового масового перенесення, коли у вас у Telegram уже є список із десятків чи сотень посилань.

Збереження змін

Зміни, зроблені на сайті (через ПКМ або закладку), спочатку живуть тільки в пам'яті браузера. Щоб вони потрапили у файл — натисніть кнопку «💾 Зберегти» у банері внизу екрана.

Що відбувається після натискання

Сайт зберігає файл у два місця одночасно:

  • На GitHub — через GitHub API, якщо в браузері є токен.
  • Локально — у теку, яку ви вибрали (File System Access API, тільки Chrome/Edge).

Після збереження сайт показує повідомлення:

Повідомлення Що це означає
✅ Записано локально та закомічено на GitHub Усе гаразд. Файл і в теці, і на GitHub.
✅ Закомічено на GitHub Токен працює, GitHub оновлено. Локальна тека не вибрана.
✅ Збережено у вибрану теку Файл у локальній теці, але на GitHub не пішов. Перевірте токен.
✅ Завантажено в Downloads Токена немає, файл врятовано через завантаження. Треба покласти його в data/ вручну.
Токен GitHub Без токена зміни з сайту не потрапляють на GitHub автоматично. Токен зберігається у localStorage браузера. Якщо Chrome блокує сторонні cookie — localStorage теж може не працювати. У такому разі дозвольте сторонні cookie у налаштуваннях Chrome.

Файли даних

Уся інформація каталогу — у теці data/. Два типи файлів:

Файл Призначення
albums.json Індекс усіх альбомів: ID, назва, опис, обкладинка (Base64), ім'я файлу з відео.
<album>.json Відео одного альбому: назва, розділ, підрозділ, URL. Наприклад, judo.json, master.json.

Формат запису відео

{
  "title": "Basic Ouchi gari",
  "section": "Зачеп",
  "subsection": "Зачеп ззовні",
  "url": "https://www.youtube.com/watch?v=e-CtiY2RLwA"
}

Поле subsection — необов'язкове. Якщо його немає — відео вважається «без підрозділу».

URL — у будь-якому форматі

Сайт розуміє всі формати YouTube:

  • https://youtu.be/ID
  • https://www.youtube.com/watch?v=ID
  • https://www.youtube.com/shorts/ID
  • https://www.youtube.com/embed/ID
  • Просто ID (11 символів)

Технічні деталі

Сайт — статичний. HTML + CSS + трохи JavaScript. Жодного сервера, бази даних чи API-ключа YouTube.

Як сайт читає дані

  • albums.json — читається через AlbumsStore.load() з cache: 'no-store'.
  • <album>.json — читається через VideosStore.load() з cache: 'no-store'.

Як сайт пише дані

  1. Користувач щось змінює → зміна у пам'яті (VideosStore або AlbumsStore).
  2. З'являється банер «Є незбережені зміни».
  3. Натискання кнопки → FileStorage.save().
  4. Спроба записати через File System Access API (якщо доступний).
  5. Спроба записати через GitHub API (якщо є токен).
  6. Якщо обидва не вдались — завантаження у Downloads.

Публікація

Сайт хоститься на GitHub Pages з гілки main. Після кожного git push GitHub автоматично перебудовує сайт — це займає 30–60 секунд.

Адреса: https://judokaua-cyber.github.io/video-catalog/

Оновлення коду

Після оновлення будь-якого .js, .css або .html файлу — обов'язково робіть git push. Кеш браузера може віддавати старі версії, тому після перевірки робіть Ctrl+Shift+R.

Для ШІ-асистента Якщо ви передаєте цей каталог іншому розробнику або ШІ-асистенту, найкорисніше — надати:
  • цей файл (manual.html) — архітектура й робочий процес;
  • manual_editing.html — покрокова робота з JSON;
  • файли з теки js/ — модулі;
  • структуру data/.
